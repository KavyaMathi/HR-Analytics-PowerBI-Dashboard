
# HR Analytics & Service Delivery Dashboard

## Project Overview
A Power BI portfolio project demonstrating how
HR operational data can be transformed into
interactive dashboards and actionable insights.

## Tools & Technologies
- Power BI
- DAX
- Power Query
- Microsoft Excel
- SharePoint
- Power Automate

## Key Metrics
- Total HR Requests
- Request Categories & Subcategories
- Average First Response Time
- Average Resolution Time
- SLA Compliance
- Automation Opportunities
- Self-Service Potential

## Project Objectives
1. Monitor HR service delivery performance.
2. Identify high-volume request categories.
3. Analyze response and resolution trends.
4. Identify automation opportunities.
5. Support data-driven HR decisions.

## Dashboard
Dashboard screenshots and a demonstration
using synthetic data will be added.

## Data Privacy
This portfolio project will use synthetic
data only. No confidential employee or
organizational information is included.
